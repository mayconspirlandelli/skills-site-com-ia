# Notes per stack

All code lives in `site/`. In any stack, `tokens.css` is generated by `gerar_tokens.py` straight into the path shown below — never copied by hand.

## Plain HTML + CSS
- `site/index.html`, one page per file (`about.html`, `contact.html`).
- `site/css/tokens.css` (generated) + `base.css` + `components.css`.
- Classes per component (`.btn`, `.btn--primary`, `.card`, `.hero__title`).
- Header and footer repeated on each page (or a simple build, if there are many pages).

## HTML + Tailwind
- Same page arrangement; `tokens.css` included and the theme extended with `tailwind.tokens.js` (`theme.extend`).
- Use the theme classes (`bg-primary`, `p-6`, `rounded-md`), not arbitrary values (`bg-[#1A56DB]`).
- Production: Tailwind CLI or Vite. CDN (`cdn.tailwindcss.com`) only for prototypes.

## Vite (+ Tailwind, with or without React/Vue/Svelte)
- `npm create vite@latest site` and pick the template; the build goes to `site/dist`.
- `site/src/styles/tokens.css` (generated), imported at the entry point (`main.js`/`main.jsx`).
- Several pages without a framework: list each HTML file in `build.rollupOptions.input` in `vite.config.js`.
- With React/Vue: one component per section (`Hero.jsx`) and UI components (`Button`, `Card`); content in a separate data file (`content.js`).

## Astro
- `npm create astro@latest site`; pages in `src/pages/`, sections in `src/components/`.
- `src/styles/tokens.css` (generated) imported in the base layout (`src/layouts/Base.astro`).
- Good for multi-page sites focused on SEO: generates static HTML by default (`dist/`).

## Next.js
- App Router: sections in `app/components/`, `tokens.css` imported in `app/layout.js`.
- `next/font` for the design system's fonts; `next/image` for images.
- Static (`output: 'export'`) if no server is needed — works on any static hosting.

## PWA (installable app)
If the briefing asked for a PWA: `manifest.webmanifest` (name, design system colors, 192 and 512px icons), `<link rel="manifest">` and a service worker. With Vite, use the `vite-plugin-pwa` plugin. Test installation in Lighthouse (PWA / "Installable" category).

## WordPress
- Block theme (`theme.json`) mapping the tokens to `settings.color.palette`, `settings.typography` and `settings.spacing`.
- Block patterns for each wireframe section.
