# Recursos úteis

Links que ajudam em várias etapas do fluxo. Use como inspiração e ferramenta — o conteúdo
das referências nunca vai direto para o site (veja as regras no `CLAUDE.md`).

## Referências de design

- **[Refero Styles](https://styles.refero.design/)** — biblioteca de estilos de sites reais para
  buscar referências (etapa de briefing e referências).

## Animações

- **[Kinetics](https://kinetics.colorion.co/#library)** — biblioteca de animações de interface
  com física de mola (stiffness/damping) em vez de easing com duração fixa. Gera CSS, React ou
  um prompt pronto para a IA.
- **[Remotion](https://www.remotion.dev/)** — cria vídeos e motion graphics com React; dá para
  usar com agentes de código e renderizar em lote. Para começar um projeto de vídeo:
  ```bash
  npx create-video@latest
  ```
  Combine com a skill `remotion-best-practices` (ver [`skills-obrigatorias.md`](skills-obrigatorias.md)).

## Skills

- **[skills.sh](https://www.skills.sh/)** — catálogo de skills para agentes de IA, instaláveis
  com um comando. Antes de instalar qualquer uma, audite (`./scripts/adicionar-skill.sh`).
- Skills de terceiros usadas por este template: [`skills-obrigatorias.md`](skills-obrigatorias.md).
