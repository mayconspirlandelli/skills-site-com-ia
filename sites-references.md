## Taste Skill
Integrado ao sistema como `design-taste-frontend`. Desenvolvido para landing pages, portfólios e reformulações: o agente lê o briefing, infere a direção de design correta em vez de usar um modelo genérico e trabalha com auditoria em reformulações, após uma rigorosa verificação prévia. Seu diferencial é trabalhar a partir dos pixels de uma referência real — scripts extraem detalhes exatos do design para um formato estruturado, em vez de simplificar a aparência em um resumo textual que o modelo precisa reinterpretar.
$ npx skills add Leonxlnx/taste-skill@design-taste-frontendnpx skills add Leonxlnx/taste-skill@design-taste-frontend
